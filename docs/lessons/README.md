# חומרי לימוד מקומיים

אלה פרקים מקוריים לתוכנית, לא העתק של הקורס שנשלח. הקישור המדויק לקורס CV הקודם
לא אותר בריפו או בחיפוש ההקשר/Drive; מיפוי אליו מסומן פתוח ולא הומצאו פרקים או זמני סרטון.
כל פרק כולל את הידע הנדרש למטלה; קוד המערכת האמיתי מצטרף לקריאה אחרי הכנת החונך.

| שבוע | פרק חובה | חלון חלופת וידאו בתוך התקציב |
|---|---|---|
| 1 | [פיתוח ואייג׳נט](01-development.md), START_HERE, NETWORK_SETUP | tracing של request וסקירת diff, שעה |
| 2 | [תיוג ו־CV](02-classical-cv.md) | פתרון דוגמת resize/נקודה ומסכה, שעה |
| 3 | [מדדים ו־ML](03-metrics-ml.md) | חישוב matching וניתוח leakage, שעה |
| 4 | [PyTorch](04-torch.md) | tracing של gradient ו־save/reload, שעה |
| 5 | [גלאי ו־BiFPN](05-detector.md) | מעבר ידני על graph, shapes ו־decode, שעה |
| 6 | [החלפה ו־inference](06-serving.md) ו־PITFALLS | אין מדיה נוספת |

35 שעות הקריאה מוקצות בטבלת התוכנית לקריאה של הפרק, קוד, ניסויים ידניים ורישום שאלות.
חמש שעות החלופה הן לתרגילי ההסבר בטבלה בלבד ואינן נספרות שוב ב־35 השעות.
אם החונך בוחר סרטון במקום חלופה, הוא מוסיף לריפו URL, טווח צפייה, משך במהירות 1×,
זמן עצירות, פרק מוחלף וסיבת הבחירה. חומר חוזר נשאר רשות; הארכת מדיה מחליפה עבודה
אחרת באותו תקציב. אין צורך לגלוש לבלוגים כדי להשלים מטלה.
