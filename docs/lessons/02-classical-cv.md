# 2 — מסכת תיוג ו־preprocessing קלאסי

## מסכה מנקודה

חוזה בקשה: image_id/revision, point במקור, label חיובי/שלילי, request_id ו־provider.
חוזה תשובה: mask בגודל המקור, encoding מתועד, גרסת provider ומקור ההצעה.
אפשר להמיר לפוליגון לצורך editor, אך יש להגדיר חורים, איים, פישוט ושטח מינימלי.
המודל מציע; המתייג מאשר. timeout, נקודה מחוץ לתמונה ו־no-mask הם מצבים נפרדים.
אם בקשה ישנה מסיימת אחרי מעבר לתמונה אחרת, התשובה נדחית לפי image revision/request ID.

ספק דמה דטרמיניסטי מאפשר לבדוק UI/API, אך אינו הוכחת סגמנטציה. חלופה קלאסית יכולה
להיות region growing: מתחילים בפיקסל, מוסיפים שכנים שדומים לצבע הזרע בתוך סף, ועוצרים
בגבול או מגבלת שטח. קובעים connectivity של 4 או 8, טווח צבע ומדיניות רעש. היא נכשלת
כשהאובייקט והרקע דומים או כשהאובייקט רב־צבעי. GrabCut צריך initialization נוסף כגון
אזור/סימוני foreground ו־background; נקודה בודדת אינה מספיקה כהגדרה מלאה שלו.
SAM 2 הוא backend נוסף ל־image prompts; בודקים API וגרסה שנבחרו בפועל. החלטה על
cache של embeddings מחייבת key שמכיל image hash, גרסת מודל ועיבוד, ולא רק שם קובץ.

## פילטרים, ספים ומורפולוגיה

קונבולוציה מחליפה כל פיקסל בסכום משוקלל של שכניו. blur יכול להפחית רעש, אבל גם
להעלים מכונית קטנה. kernel גדול ביחס לאובייקט הוא שינוי בהנחת המחקר. קובעים border
handling כי קצוות תמונה עשויים להתנהג אחרת. Sobel מודד נגזרת מקומית; סף על הגרדיאנט
מוצא קצוות ולא בהכרח אובייקטים. אין להסיק ממפה שנראית חדה שדיוק הגלאי השתפר.

במסכה בינארית erosion מצמצם foreground ו־dilation מרחיב אותו. opening הוא erosion
ואז dilation; closing בסדר ההפוך. opening עשוי להסיר רעש וגם אובייקט אמיתי קטן;
closing עשוי לסגור חור וגם לחבר שני אובייקטים. מציגים דוגמה לכל אחת מהתקלות.
connected components תלוי ב־connectivity; פיקסלים נוגעים באלכסון משנים מספר מופעים.
לשינוי annotation יש לשמור מקור וגרסת transform, אחרת לא יודעים אם המודל או התיוג השתנו.

## טווחים וגאומטריה

RGB uint8 שונה מ־float בטווח [0,1], ושניהם שונים מ־standardized channels. OpenCV
עשוי לעבוד ב־BGR בחלק מממשקי הקריאה. מתעדים מה קורא הקוד האמיתי. חיסור על uint8
עלול לגלוש; עוברים לטיפוס מתאים לפני חישוב. resize חייב לעדכן boxes/masks יחד עם
התמונה. למסכות תוויות משתמשים באינטרפולציה שמשמרת IDs; bilinear של class IDs
ממציא תוויות. padding מתועד כדי שאפשר יהיה להחזיר פלט למקור.

## ניסוי ששומר על השאלה

בוחרים שינוי אחד כגון contrast normalization או תיקון מסכה. baseline ושינוי מקבלים
אותו split, אותן תמונות ואותם thresholds. מודדים גם מטריקה וגם שגיאות לפי גודל,
תאורה וקצוות; שומרים before/after/overlay של דוגמאות שנבחרו מראש, לא רק הצלחות.
אם בוחרים פרמטר לפי validation, לא מדווחים אותו סט כאומדן test בלתי תלוי.
מותר ששינוי לא משפר: מסקנה תקפה עם כשל מוסבר טובה משיפור מקרי בלי עקיבות.

תרגיל: חשבו תוצאת opening על מסכה עם שני אובייקטים קטנים, חזו מה יקרה ל־recall,
ואז השוו לתוצאה אמיתית. קראו את ה־preprocess של train ושל serving וסמנו הבדלים.
