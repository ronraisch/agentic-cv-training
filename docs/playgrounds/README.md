# Offline playgrounds

Open any of the four HTML files in a browser from your local training folder. You can also download an individual file using **Download raw file** on GitHub before going offline. The pages include their own styles, code and synthetic examples. JavaScript runs locally in the browser.

| Playground | What you can change | Related reading |
|---|---|---|
| [Decision boundaries](decision-boundaries.html) | Dataset, hidden units, activation, learning rate, label noise and features | [ML foundations](../reading/ml-foundations.md) |
| [Image filters](image-filters.html) | Noise, blur radius, edge threshold and displayed processing stage | [CV filtering](../reading/cv-filtering.md) |
| [Attention map](attention-map.html) | Query, temperature, causal mask and one key or value | [Attention](../reading/dl-attention.md) |
| [Design patterns](design-patterns.html) | Direct function, strategy and pipeline on the same input and rule | [Python tools](../reading/python-tools.md) |
