Find edges in a noisy plate

Use a synthetic greyscale plate to see how smoothing changes the evidence that an edge detector receives. Compare the same pixels before and after processing.

Processing controls

Keep noise fixed. Increase the blur radius until the speckle fades. Then inspect the narrow character strokes. Switch to gradient magnitude to see which responses the threshold will keep.

How the filter works

The box filter averages a square neighbourhood, extending the nearest border value at image boundaries. Sobel estimates horizontal and vertical intensity changes from 3 × 3 neighbourhoods. The binary view marks pixels whose gradient magnitude, scaled by 1/4, meets the threshold. Edge count measures response density on this synthetic image.
