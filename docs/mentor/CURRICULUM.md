# Curriculum and scheduling

[Training index](../TRAINING_INDEX.md) · [Trainee guide](../training/TRAINEE_GUIDE.md)

## Trainee time budget

Use the [trainee guide's assignment table](../training/TRAINEE_GUIDE.md#practical-work--active-hours-not-elapsed-runtime) for the complete assignment order and its [time budget](../training/TRAINEE_GUIDE.md#total-time-and-waiting) for scheduling. Count study, viewing, corrections and active work once each. Schedule around readiness and record unattended compute separately.

## Mentor availability

Schedule the [two mentor conversations for each part](READING_AND_SESSIONS.md#two-conversations-for-each-part) around trainee readiness. Reserve four hours separately for mentor preparation. Use the [lab readiness prompts](READING_AND_SESSIONS.md#first-pass-readiness-by-lab) and [mentor conversation topics in each syllabus](../TRAINING_INDEX.md).

Use [environment setup](../setup/README.md) to arrange access, approved assets and the internal handoff before the trainee needs them.

## Completion and fallback

Record concept understanding and practical verification separately. If access is blocked, record
the missing prerequisite and its owner. Use the 16-hour contingency for access and remediation.
If it runs out, agree on a smaller dataset or a prepared component with the mentor while keeping
the core learning goals.
