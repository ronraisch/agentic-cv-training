# Start here

Start with [workspace setup](../labs/research/00-installations.md). The [trainee guide](TRAINEE_GUIDE.md) has the full assignment list and time estimates.

| Step | What to do | How to check it |
| --- | --- | --- |
| 1. Workspace | Install VS Code, attach to your OpenShift pod and set up Python/uv through Artifactory. Ask the mentor for access and the setup fixture. | Run the fixture in the pod and stop at a breakpoint. |
| 2. Python | Complete [Shape Rendering](../labs/research/00-python-manual.md) by hand in the pod. | Save and reopen a render. Show a valid and a malformed input at review. |
| 3. OMP | After Python sign-off, return to [workspace setup](../labs/research/00-installations.md) to configure OMP, the approved local model and the selected Matt Pocock skills. | Use the agent to read an approved fixture from the pod and verify the result yourself. |
| 4. Labeling and SAM2 | Get the internal checkout and a known input from the mentor. Complete [polygon support](../labs/research/01-polygons.md) and [build the first SAM2 service by hand](../labs/research/01b-sam2-service.md). | Trace a saved annotation through reload and verify inference through the deployed service. |
| 5. CV, ML and Deep Learning | Follow the [four-part training index](TRAINING_INDEX.md). Use each lab's start card for the required inputs and mentor checkpoints. | Bring a reproducible result and a failure case to review. Complete RabbitMQ/SAM3 before the video handover. |

For local rehearsal, see the [ResearchLab demo](BASELINE.md). For internal work, confirm the assigned checkout, access and assets with your mentor using the [environment handoff](RESEARCH_ENVIRONMENT.md) and [preflight](PREFLIGHT.md).

After Python review, [ask the approved agent for explanations](RESEARCH_WITH_AGENTS.md#when-you-get-stuck). Bring unresolved questions to your mentor. Use the [dataset catalog](DATASETS.md) to acquire approved inputs for each assignment.
