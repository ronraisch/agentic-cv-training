## Viewing and study

Recommended first-pass study: 10–14 h; viewing/reflection: 3–5 h. These ranges are estimates, not hard caps or measured course runtimes. Record actual effort and deepen unfamiliar subjects.
See [course videos](../reading/development.md#videos-and-course-selection).

## Mentor conversations

Session 1: brief foundations check, then manual code review and an unseen input. Session 2: service/data boundaries, state and failure recovery; later agent/skill use after the manual boundary. The mentor may ask theory questions throughout.

The mentor continues using the existing theory questions. Understanding is assessed, not reading completion.
