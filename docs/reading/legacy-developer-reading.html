Reading & Viewing Materials

For each topic, one or two short resources — enough to follow a researcher's explanation, not to become an expert. Total watch/read time is roughly 5-6 hours if done end to end.

A. Learning Paradigms & Task Types

1. Supervised, unsupervised & self-supervised learning

Article: Google for Developers — What is Machine Learning? — the core split: supervised learning uses labeled data, unsupervised learning finds structure in unlabeled data, and where self-supervised learning (creating its own labels from the data itself — the approach behind most modern LLM pretraining) fits in.

Article: IBM — Five machine learning types to know — broader reference covering supervised, unsupervised, self-supervised, and reinforcement learning side by side.

2. Common task types: classification, regression, clustering, segmentation, etc.

Article: Medium (Analytics Vidhya) — Image Classification vs. Object Detection vs. Image Segmentation — clear visual comparison of three commonly confused task types.

Article: Medium — Regression, Classification, and Clustering: Understanding Core Machine Learning Concepts — ties task type back to the supervised/unsupervised distinction above (classification & regression are supervised; clustering is unsupervised).

B. Neural Network Fundamentals

3. Linear layer & 4. Activation function

Video: 3Blue1Brown — But what is a neural network? (Ch. 1) — 19 min. Shows what a "layer" of weights and biases actually is, and why a non-linear activation function has to sit between layers.

Article: Google ML Crash Course — Activation Functions — short reference on ReLU/sigmoid/tanh with interactive plots.

5. Loss functions & gradient descent

Video: StatQuest — Gradient Descent, Step-by-Step — 24 min. How a loss function measures "wrongness" and how the model's weights get nudged to reduce it. This is what "training" a model means, mechanically.

6. Overfitting & regularization

Video: StatQuest — Regularization Part 1: Ridge (L2) Regression — 20 min. Explains overfitting and how regularization counters it; the same idea (penalizing complexity) shows up as weight decay/dropout in neural nets.

7. CNN

Video: 3Blue1Brown — But what is a convolution? (CNN chapter) — 23 min. Visual build-up of what a convolution does to an image, the operation CNNs are built on.

C. Evaluation & Metrics

8. Evaluation & basic metrics: accuracy, precision, recall — why isn't accuracy enough?

Article: Google for Developers — Classification: Accuracy, recall, precision, and related metrics — the classic tumor-classifier example showing how a model can have 99% accuracy and still be useless on an imbalanced dataset.

Video: StatQuest — Machine Learning Fundamentals: Sensitivity and Specificity — 15 min. Same ideas as precision/recall, walked through with a confusion matrix.

D. Language Model Building Blocks

9. Tokens

Video: Andrej Karpathy — Let's build the GPT Tokenizer — long (2h13m); watching the first 20-30 minutes is enough to get why text is split into tokens and why that causes weird LLM behavior (e.g. bad at arithmetic/spelling).

10. Embeddings

Article: Jay Alammar — The Illustrated Word2vec — how words (and tokens generally) become vectors that encode meaning; foundational for understanding embeddings used everywhere downstream.

11. Attention

Video: 3Blue1Brown — Attention in transformers, visually explained (Ch. 6) — 26 min. The mechanism that lets a model decide which other tokens are relevant to each token.

12. Encoder & 13. Decoder

Article: Jay Alammar — The Illustrated Transformer — the classic reference diagraming the encoder and decoder stacks and how they connect.

14. Transformer architecture — putting it together

Video: 3Blue1Brown — But what is a GPT? Visual intro to Transformers (Ch. 5) — 27 min. Ties tokens, embeddings, attention, and decoders together into "how GPT actually works."

E. Retrieval & Applied LLM Systems

15. Vector quantization

Article: Qdrant — What is Vector Quantization? — why and how vectors get compressed for storage/search at scale.

16. Retrieval by vector similarity

Article: Pinecone — Introduction to Faiss and Nearest Neighbor Indexes for Similarity Search — how "find the closest vectors" search actually works under the hood.

17. Retrieval-Augmented Generation (RAG)

Article: Pinecone — Retrieval-Augmented Generation — connects retrieval + embeddings + an LLM into the RAG pattern that ties sections D and E together.

F. Training, Deployment & Optimization

18. Model inference vs evaluation in PyTorch

Docs: PyTorch — Saving and Loading Models — covers model.train() vs model.eval() and why forgetting to switch modes silently breaks inference (dropout/batchnorm behave differently).

19. Fine-tuning & transfer learning (incl. LoRA/PEFT)

Docs: Hugging Face — Fine-tuning a pretrained model — what fine-tuning means as a follow-on to pretraining.

Docs: Hugging Face — LoRA conceptual guide — why teams fine-tune a small set of extra parameters instead of the whole model.

20. Model optimization

Article: Ultralytics — Inference Latency — plain-language definitions of latency vs throughput and the main levers (batching, quantization, distillation, pruning) used to optimize inference.

21. Model quantization

Article: Hugging Face — A Gentle Introduction to 8-bit Matrix Multiplication — the "why" of quantization (smaller, faster, small accuracy cost) with a concrete int8 example.

22. Compiling models (general concept — no specific tool)

Article: Medium (Geek Culture) — AI Compilers Demystified — what "compiling" a model means in general: turning a graph of operations into optimized machine instructions via steps like operator fusion and kernel generation, which is why a compiled model runs faster with no change to its architecture. The specific tool (PyTorch, TensorFlow/XLA, TVM, etc.) matters less than this underlying idea.

23. Model parallelism vs data parallelism

Docs: Hugging Face — Parallelism methods — the core distinction: copying the model across GPUs (data parallelism) vs splitting the model itself across GPUs (model parallelism).
